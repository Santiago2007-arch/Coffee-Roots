# Coffee Roots — Online Shopping Interface

A responsive, interactive English-language Colombian coffee store prototype for an educational design activity.

## How to run
Open `index.html` in Chrome, Edge, or Firefox. No installation or server is required. (Web fonts require internet; fallback fonts work offline.)

## Features
- Four coffee products with names, descriptions, roast level, origin, and COP prices.
- Filter by roast and add in-stock coffees to the cart.
- Open cart, adjust quantities, remove items, and see the calculated total.
- Delivery is 8,000 COP or free for orders of 120,000 COP or more.
- Sold-out Midnight Reserve offers an available substitute (Andean Sunrise).
- Review order and finish a simulated checkout with confirmation.
- Cart stays saved in the browser between visits.
- Responsive layout and accessible buttons, labels, and status messages.

**No real payment processing, order processing or shipping.**
